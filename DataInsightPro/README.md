# 🧬 PrePersona

PrePersona is an AI-powered digital clone application that models your personality, decision-making, and thought patterns.

## 🚀 Features
- Trains on your unique responses to mimic behavior
- Predicts decision paths in hypothetical scenarios
- Streamlit UI for live testing and persona interaction

## ⚙️ Tech Stack
Streamlit • Groq API • LangChain • Python

## 🧠 Inspiration
Born from the idea of digital consciousness — if your future self could advise you, what would it say? PrePersona explores this intersection of AI, psychology, and philosophy.

## 🌱 Future Enhancements
- Embedding-based personality models
- Feedback loop for accuracy improvement
- Integration with platforms like Discord or web widgets
