
# Nike UI Website

A sleek and responsive frontend website inspired by Nike's brand aesthetics, built to showcase advanced UI/UX capabilities using **React** and **Tailwind CSS**. The project highlights modular layout design, animation effects, and brand-conscious visual hierarchy — optimized for performance and presentation.

## 🚀 Features  
- Hero section with bold typography and call-to-action buttons  
- Product highlights with grid layout and hover animations  
- Scroll-triggered transitions and smooth section navigation  
- Mobile responsiveness using Tailwind's breakpoint utilities  
- Modular components for Navbar, Footer, Cards, and Category Blocks  
- Embedded brand visuals and color themes true to Nike's identity

## ⚙️ Tech Stack  
React • Tailwind CSS • JSX • JavaScript  
Optional Hosting: GitHub Pages • Vercel • Netlify

## 🧠 Inspiration  
Crafted to demonstrate frontend precision through brand emulation. Nike’s legacy of minimalist strength and kinetic design provided the foundation for layout decisions, typography choices, and animation integration. This project is both a style study and a performance demo.
