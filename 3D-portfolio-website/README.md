# 3D Portfolio Website 🌐

An immersive, interactive 3D personal portfolio built using modern web technologies to showcase skills, projects, and contact information in a visually stunning way.

## 🔗 Live Demo

**👉 [View Portfolio](https://helpful-malabi-05470f.netlify.app/)**

---

## 🚀 Features

- 🎥 **Real-time 3D animations** using React Three Fiber  
- 🌐 **Responsive UI** across all screen sizes  
- ✨ **Smooth transitions** with Framer Motion  
- 💡 **Dynamic lighting & 3D effects**  
- 📬 **Working contact form** via EmailJS  
- 🧠 Modular, clean code structure  

---

## 🛠️ Tech Stack

| Category          | Technologies Used                                      |
|-------------------|--------------------------------------------------------|
| **Frontend**      | React.js, Tailwind CSS, Vite                          |
| **3D Rendering**  | Three.js, React Three Fiber, Drei                     |
| **Animation**     | Framer Motion                                         |
| **Routing**       | React Router DOM                                      |
| **Email Service** | EmailJS                                               |
| **Deployment**    | Netlify                                               |
