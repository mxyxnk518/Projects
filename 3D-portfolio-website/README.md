
# 🌐 3DPortfolioSite

3DPortfolioSite is a visually immersive developer portfolio built with Three.js and React. Designed to showcase your projects, skills, and personal brand through animated canvases and responsive layouts, it merges creative storytelling with scalable tech deployment.

## 🚀 Features
- Dynamic Three.js scenes with scroll-triggered animations  
- React-powered sections for About, Projects, Contact, and Resume  
- Interactive project cards with hover tilt and GitHub/demo links  
- Tailwind CSS layout for clean and responsive design  
- Embedded contact form and resume link integration

## ⚙️ Tech Stack  
React • Tailwind CSS • Vite • Three.js • React-Three-Fiber • @react-three/drei • GitHub • Vercel / Netlify

## 🧠 Inspiration  
Blending artistic self-branding with technical depth — this portfolio reflects not just what I build, but **how** I think. Each section explores the path from early curiosity to confident execution in full-stack development.
