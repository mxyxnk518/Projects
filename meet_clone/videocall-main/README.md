
# 📞 MeetClone App

MeetClone is a browser-based video meeting interface built using vanilla JavaScript and WebRTC. Designed to emulate key functionality of platforms like Google Meet, the app facilitates peer-to-peer video calls, room creation, and live interactions — all within a clean and responsive UI.

## 🚀 Features  
- Real-time video and audio communication  
- Unique room generation for private meetings  
- Join functionality via dynamic links or room ID  
- Local camera/mic toggle and mute options  
- Scalable interface for multiple participants  
- UI interactions built with custom JavaScript logic and CSS transitions

## ⚙️ Tech Stack  
JavaScript • HTML • CSS • WebRTC • Socket.io (optional for signaling)  
Optional Deployment: GitHub Pages • Vercel • Firebase Hosting

## 🧠 Inspiration  
Born from the need to create simple, secure video rooms without the complexity of full-scale enterprise platforms. MeetClone offers foundational real-time interaction tools for developers experimenting with live communication features in the browser.

## 🌱 Future Enhancements  
- Chat functionality using WebSockets  
- Screen sharing toggle and permissions  
- Participant list and access control  
- Audio visualizer and echo cancellation logic  
- UI polish with Tailwind or component libraries (e.g. DaisyUI)
