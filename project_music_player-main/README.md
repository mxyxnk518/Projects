# 🎧 Lyriks

Lyriks is a sleek music streaming app inspired by Spotify, featuring synchronized lyrics and trending tracks.

## 🚀 Features
- Discover trending music via RapidAPI
- Real-time lyrics sync for immersive listening
- Tailwind-powered responsive UI with Redux state handling

## ⚙️ Tech Stack
React • Redux • Tailwind CSS • RapidAPI


## 🧠 Inspiration
Music moves us — Lyriks aims to match that feeling through clean design, seamless playback, and lyrical depth.

## 🌱 Future Enhancements
- User accounts and playlists
- ML-powered recommendations
- Dark/light mode toggle for accessibility
