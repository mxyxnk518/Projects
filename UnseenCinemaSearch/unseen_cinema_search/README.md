

# 🎥 Unseen Cinema Search

Unseen Cinema Search is a React-based movie discovery app that helps users find hidden cinematic gems and suitable films based on personalized criteria. Built with clean UI logic and modern component design, it focuses on speed, interactivity, and minimal distractions — optimized for users who crave substance over popularity.

## 🚀 Features  
- Movie search interface with real-time filtering  
- Intuitive input system for genre, year, and mood-based selection  
- Modular React components for scalability and code clarity  
- Animated transitions and responsive layout for seamless experience  
- Results display with image cards, ratings, and brief descriptions

## ⚙️ Tech Stack  
React • JavaScript • JSX • CSS Modules / Tailwind CSS (optional styling)  
Suggested Hosting: Vercel • Netlify • GitHub Pages  

## 🧠 Inspiration  
Built for film lovers who want more than mainstream recommendations. Inspired by the idea that hidden masterpieces deserve better discovery tools — Unseen Cinema Search helps users explore the thoughtful, underrated side of entertainment.

## 🌱 Future Enhancements  
- API integration with TMDb or OMDb for deeper metadata  
- Bookmarking and watchlist feature using LocalStorage  
- Sentiment-based suggestions using basic NLP filters  
- Dark mode toggle and user preference caching
