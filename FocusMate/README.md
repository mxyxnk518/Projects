

# 🎯 FocusMate – AI-Powered Study Tracker

FocusMate is a real-time productivity and accountability app built with React and JavaScript. It leverages facial recognition to monitor student focus, enabling smarter study sessions by tracking distractions and promoting engagement. Students can log assignments, track deadlines, and visualize their focus patterns — all in an intuitive dashboard interface.

## 🚀 Features  
- **Face Detection Monitoring**: Uses webcam and ML models to detect attention patterns during study sessions  
- **Distraction Alerts**: Triggers real-time feedback when gaze shifts or eyes close  
- **Assignment Logging**: Allows students to add, edit, and manage upcoming tasks  
- **Focus History**: Displays session-level graphs and attention scores  
- **Responsive UI**: Mobile-first design with adaptive layout and animations  
- **Session Timer + Analytics**: Tracks duration, effectiveness, and interruption events

## ⚙️ Tech Stack  
React • JavaScript • HTML/CSS • TensorFlow.js / MediaPipe • Redux (for state management)  
Optional Tools: Firebase • Chart.js • FaceAPI.js • Tailwind CSS  
Suggested Deployment: Vercel • Netlify • GitHub Pages

## 🧠 Inspiration  
Designed for students who struggle with digital distractions and task overload, FocusMate blends cognitive science with front-end innovation. The app doesn't just track — it **coaches**, creating a smarter study workflow through visual feedback and active self-regulation.
